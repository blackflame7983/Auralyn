# #98 履歴失効理由の個別表示（2026-10-28・ローカル実装）

## 変更

NR・内蔵処理・固定ゲインの読み取り用snapshotに、エンジンが把握する履歴の失効根拠を追加した。画面はトークン不在だけで「未作成」「編集による失効」を推測しない。

| コード | 根拠 |
| --- | --- |
| `not_created` | このエンジンで対象の履歴がまだ作られていない |
| `settings_changed` | 対象設定の手動編集・変更 |
| `input_changed` | 入力機器・チャンネル・入力ゲイン等の条件変更 |
| `learning_changed` | NRの周囲測定・学習条件変更 |
| `new_measurement` | 新しい測定・録音の開始 |
| `stream_changed` | 音声の開始・停止またはストリーム条件変更 |
| `stream_failed` | 音声処理の障害 |
| `conditions_changed` | その他の関連する音声条件変更 |

- 履歴が有効なら理由はnull。反映待ちと本番保護は失効と分ける。
- 履歴を消費した最初の理由を、後の無関係な操作で上書きしない。新たな有効履歴ができれば以前の理由を表示しない。
- 理由は履歴と同じエンジン世代内で保持する。再起動後に過去の履歴・理由をディスクから復活させない。新しいエンジンは「このエンジンでは履歴がまだありません」と表示する。
- 理由コードが欠落する旧sidecar、未知コード、取得失敗は未作成と決めつけず、確認不能として再取得を案内する。
- 停止中も既存エンジンへの読み取り専用要求で理由を確認できる。エンジン不在時は取得不能とし、音声を自動開始しない。停止・障害中はUndo/Redoを無効にする。
- 表示のための新しい定期ポーリング・履歴の永続化・音声callback内の処理は追加していない。履歴の取得は録音画面の所有権を変更しない。

## 検証

- ロックどおりの分離環境（Vite 8.3.5／Vitest 4.1.12）で全1,185件成功。理由表示の対象UIは13件成功し、日英の理由、未作成と失効の区別、未知コード、取得失敗後の古い理由非表示、停止中の非自動開始を検査した。型検査とViteビルドも成功。
- 全体テストで既存の復旧localeテストに残っていたStartの5引数期待を検出。PR #122の製品コードが7引数へ対応済みのため、テストの期待値だけを現行契約へ修正した。
- Rustはライブラリ503件と機器不要の統合テストが成功。実音声開始を伴う `test_audio_engine_lifecycle`、実VST GUIの `test_ott_editor_loading` は明示的に除外し、既定のignoredテストも実行していない。
- 全体テスト後にNRの失効原因保持を補強し、設定編集後の入力変更でも元の原因を保持することを含め、NR関連6件と全ターゲット確認・Clippyを再検証した。最後の変更後の全Rustテスト再実行とは区別する。
- PR前レビューで、承認済み学習プロファイルの期限切れ・非有限入力による失効が手動編集と誤分類される点を修正した。手動設定と学習メタデータの比較を分け、NR関連7件で学習由来の失効と先行する手動編集理由の保持を再検証した。
- `cargo check --locked --all-targets`、`cargo clippy --locked --all-targets`、書式・差分チェック成功。既存の引数数警告4件とincremental cacheのコピーへのフォールバック警告は残る。
- ブラウザモックで3対象に異なる理由を与え、明示取得後の未作成／設定編集／新測定の表示と無効ボタンを確認。日本語900×600・1280×720・1920×1080で表示を確認し、900×600と1280×720では文書の横はみ出しなしを確認した。

## PR #123 レビュー後の補強

- 承認済み学習プロファイルを含む履歴は、測定期限切れで再束縛できなければその時点で破棄し、失効理由を保持する。再束縛できる履歴は従来どおり残す。
- これにより、期限切れ後のNR手動編集で `learning_changed` が `settings_changed` へ変わることを防ぐ。
- Undo／Redo両方向の履歴と、SetNoiseControlConfig／SetNoiseReductionの両成功経路に相当する順序について、期限切れ→手動変更後の理由保持・古いトークン非公開・新しい履歴による置換を検査する回帰テストを追加した。修正前の失敗を確認してから修正した。実streamは起動しない。
- 上記の「ローカル実装のみ」「未公開」は初回実装時点の記録。公開状況はPR #123を参照する。実機未確認の境界は継続する。
