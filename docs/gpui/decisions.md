# GPUI 移行の決定

GPUI で画面を作り直すときの、理由つきの決定。新しい決定は上に足し、取り消すときは消さずに取り消しの理由を書く。
書き方の知見は [knowledge.md](knowledge.md)。移行の分岐点は [audio-session-controller.md](../plans/audio-session-controller.md) 13.2（J-11）。

| 日付 | 決定 | 理由 |
| :--- | :--- | :--- |
| 2026-11-27 | 画面の書体を Noto Sans JP（Google Fonts の可変フォント、SIL OFL 1.1、`src-gpui/assets/fonts/`）にし、実行ファイルに入れて `Theme.font_family` に入れる（`typeface.rs`）。部品（gpui-kit）の色・角丸も `design/tokens.json` から塗る（`color::set_theme` の `paint_parts`）。選んだ印（ghost の選択・一覧）は primary を 16% 重ねた色、スイッチ・スライダー・主ボタンは primary | 利用者が「文字数の多い所で目が痛い・滑らかさが足りない」と指摘。Yu Gothic UI は 100% 表示の小さい字で線が細く、暗い地では ClearType の色にじみが目立った。候補（IBM Plex Sans JP・Noto Sans JP・Zen Kaku Gothic New・BIZ UDPGothic・M PLUS 2）を同じ文で比べ、線の太さが均一で和欧の混植と数字（U+2212 の負号が欧文幅）が揃う Noto Sans JP にした。部品は gpui-kit の既定（灰色・青）のままで、ブランドの色（オーロラ・ゲーミングのマゼンタ）がスライダーや選択に出ていなかった。ポップオーバー・ツールチップは窓の根の書体を使うので、`MainView` でなくテーマに入れる |
| 2026-11-26 | ボイスチェックの試聴は、中核の `voice_check_preview` のセッションで、配信の送り先とは別の出力先に鳴らす。録音があり音づくりの画面を出している間は開き（戻ったときも開き直す）、録り直す前・画面を離れたとき・窓を隠したとき・音声が止まったときに閉じる。失敗したら開き直すボタンを出す。出力先を選び「OBS・通話アプリが取り込んでいないと確かめた」に印を付けるまで再生させず、印はその出力先に付ける（別の出力先を選ぶと外れる）。音量合わせ（level match）はまだ使わない | 主の出力で鳴らすと録った声が配信に乗る。Tauri 版と同じ確認を求める。GPUI 版は命令を1本のスレッドで順に実行するので、Tauri 版の答えの追い越し対策（revision・sequence）は要らない |
| 2026-11-26 | ボイスチェックは、まず録音（最大 10 秒）と WAV 保存（加工前・加工後）だけを音づくりの画面の下に置く。再生は入れない。保存は音声が流れているときだけにし、画面を離れたとき・窓を隠したときは録音を止める | 中核の `play_voice_check` は主の出力（配信の送り先）へ流れるので、配信に録った声が乗る。Tauri 版の試聴は配信に乗らない別の出力先（`voice_check_preview` のセッション）で鳴らすので、GPUI 版も同じ形で次に作る。止めても録った音は子に残るが、子が落ちて作り直されたときは新しい子が通知を出さないまま何も持たないので、止まっている間は保存できるように見せない |
| 2026-11-26 | 保存した構成に削除・書き出し・読み込みを足す。削除は確認の窓を出す。書き出しは接続（`audioConfig`）を除く（Tauri 版の既定と同じ）。読み込みはファイルの中の名前で取り込み、同じ名前（大文字・小文字を区別しない）があれば取り込まずに知らせる。接続だけの構成（GPUI 版の一覧に出ない）と、構成として読めないファイルも取り込まずに知らせる。退避の名前（`__backup_previous`）は、退避がまだ無くても保存・読み込みに使わせない。ファイルの窓は GPUI の `prompt_for_new_path` / `prompt_for_paths` を使う | 削除は戻せない。Tauri 版の読み込みは同じ名前を黙って上書きするが、保存で上書きさせないのと揃え、退避を外から書き換えられないようにする（Windows のファイル名は大文字・小文字を区別しないので、退避の名前は大小を無視して断る）。一覧に出ない構成を取り込むと、GPUI 版からは見えも消せもしない。GPUI の窓を使えば `rfd` を足さずに済む（種類の絞り込みはできず、すべてのファイルが出る） |
| 2026-11-25 | VST の画面の下に「保存済みの構成」を置く。Tauri 版と同じ `presets/` のファイルを読み書きし、一覧・適用・直前の状態に戻す・名前を付けて保存ができる。扱うのは VST の並び・ノイズ低減・声を整える設定だけで、保存では接続（`audioConfig`）を含めず、適用でも接続は変えない（接続だけの構成は一覧に出さない）。適用の前は今の状態を退避（`__backup_previous`）へ保存し、確認の窓は出さない。同じ名前への保存（上書き）はさせない。削除・書き出し・読み込みはまだ無い（2026-11-26 に足した） | GPUI 版は入出力の音量・チャンネルを Tauri 版の形（dB・`ProfileAudioExtras`）で持たないので、接続を保存すると違う音量を書いてしまう。適用は退避からいつでも戻せるので確認を挟まない。上書きは戻せないので、名前を変えさせる。VST の並びは GPUI 版の並び（`gpui_rack.json`）として読み直し、起動時の復元と同じく読めなかった VST も枠として残す |
| 2026-11-25 | 音づくりのノイズ低減の詳細に「環境に合わせる」（測定値で調整・会場）と、周囲の音の測定（3秒測る・中止・状態を更新、結果を見て「話していない」と確かめてから採用）を足す。測定の欄を出している間は、Tauri 版と同じく 500ms ごとに状態を読む。測っている途中で画面を離れると中止する。測定条件の詳細（機器・ch・ゲイン・時刻）はまだ出さない | 測定は、マイク音量・チャンネルの変更や 30 分の期限でも古くなるので、測っている間だけ読むと、古い結果に「使う」を出したままになる。測定はこの画面からしか始めないので、Tauri 版の「自分が始めた測定か」の区別は要らない。採用の前の確認と、測定の組（epoch・generation）を添えて頼む形は Tauri 版と同じ |
| 2026-11-25 | 接続の画面に周波数とバッファを足す。候補は機器が知らせた範囲（WASAPI は出力、ASIO は入出力の両方）に入るよく使う値・範囲の端・保存した値で、先頭に「自動」（エンジンが機器に合わせて決める）を置く。最初は同じ接続方式で保存した値、候補に無ければ「自動」。マイクや出力先を選び直しても、新しい候補にあれば選んだ値を残す。「自動」で開始すると、エンジンが使った値（バッファは分からないとき 512）が保存されるので、次に開くとその値が選ばれる | Tauri 版は 48 kHz・512 を既定にして範囲外の値を「非対応」と示すが、GPUI 版は選べない値を出さず、分からないときはエンジンに任せる方が迷わない。範囲の判定は `auralyn-ui-model` の `connect` で試験する。「自動」を覚えるには保存の形（Tauri 版と共通の `last_audio_config.json`）を変える必要があり、帯の開始も保存した値を使うので、画面は保存した値をそのまま見せる |
| 2026-11-25 | 「大きな音を抑える」の天井（−12〜−0.1 dBFS、0.1 刻み）と復帰時間（20〜1000 ms、10 刻み）を、カードの「詳しい設定」のスライダーで変える。離したときに両方を送り、ON/OFF は今のまま。音声が止まっていて状態を読めない間は操作させない。保存はしない | Tauri 版は数値の入力と「適用」のボタン。GPUI 版はほかの音づくりと同じく、スライダーを離したら送る。範囲はエンジンの `Config::validate` と同じで、刻みにそろえるのは `auralyn-ui-model` の `peak::snap`。再起動で既定に戻るのは Tauri 版と同じ |
| 2026-11-25 | VST ごとの音量（0〜200%、1% 刻み）とミュートを、並びの各枠の下の行に出す。音量はスライダーを離したとき（キーでは1歩ごと、続いた分は最後の値だけ）に送り、ミュートはボタンで切り替える。どちらも `gpui_rack.json` に保存し（`RestorePluginRequest` の `gain`・`muted`）、起動時と子が落ちたあとの読み直しで戻す | Tauri 版のカードと同じ範囲。離したときだけ送るのは、動かしている間に毎回保存しないため（音づくりのスライダーと同じ）。百分率はスライダーの値を出すので、動かしている間もついてくる |
| 2026-11-25 | 設定の画面は、表示言語・Windows との連携（トレイ・Alt+M）の状態・版から始める。表示言語は `gpui_locale.json` に保存し、`--lang` を付けなければそれで開く。無ければ Tauri 版の `display-locale.json` を読むが、そこへは書かない。試作の確認用の欄（IME の入力欄）は外す | 言語は毎回の起動で選び直させない。Tauri 版のファイルはトレイ用の写しで、Tauri 版が起動のたびに自分の画面の言語で書き直し・削除するので共有できない。自動起動は Tauri 版の登録（同じ Run キー）を書き換えるので、置き換えまで移さない。IME の確認は試作の判定で済んでいる |
| 2026-11-25 | 窓の × では終了せず、トレイへ隠す（音は止めない）。終了はトレイの「終了」。トレイを作れなかったときだけ、× で終了する。窓を隠すのは Win32 の `ShowWindow` を直接呼ぶ（`raw-window-handle`・`windows-sys` を足す） | Tauri 版と同じ動き。配信中に窓を閉じて音が止まると困る。GPUI には窓を隠す手段が無い（`App::hide` は Windows で何もしない）。トレイが無いと戻す手段が無いので、そのときは閉じる |
| 2026-11-25 | 音づくりの画面に「大きな音を抑える」（ピーク保護）の ON/OFF を足す。天井と復帰時間は今の値のまま変えず、設定は保存しない（アプリを起動し直すと OFF）。状態は音づくりの画面を開いたときと、開始・停止のあとに読む | Tauri 版と同じく、保護はアプリの中だけで持ち、エンジンの作り直しには `AudioHost` が引き継ぐ。数値の調整は「数値の詳細を表示」がまだ無いので移さない。止まっているときは読めないのが普通なので、読むだけの失敗は帯に出さない |
