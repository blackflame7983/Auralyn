- 表示用途（配信・通話／音楽鑑賞）をセットアップの音声用途から分離した。初回はセットアップ用途を参照し、明示選択後は独立した表示設定を優先する。表示切替から音声設定・送出・ミュートは変更しない。

- 内蔵処理の片方だけが有効なら一部ONとし、声の処理と残響の内訳を提供する。現在の世代の設定値と受け側への到達は区別する。

- フッターから通常のNR・VST状態とボイスチェックを集約した。出力メーター、音量、原音比較、音声の詳細、異常・反映未確認の警告を維持する。緊急ミュートはヘッダーに残す。

- 用途別ウィンドウは [ISSUE_109_WINDOW.md](ISSUE_109_WINDOW.md) のとおり。音楽900×600、配信・通話960×640を下限とし、作業領域が小さければ下限も収める。初回は既存の復元状態を尊重する。
