# 内蔵ディエッサー（#457）

外部 VST を入れずに、サ行の鋭さを抑える動的ハイシェルフを追加する。既定は OFF。旧設定・旧プロファイル・旧 bundle に項目が無いときは OFF のまま読む。第三者の実装や係数表は参照していない。RBJ Audio EQ Cookbook の high-shelf（S = 1）と、検出用の定ピークバンドパスだけで組んでいる。

相補分割（`high = x − LPF(x)` にゲインを掛ける形）は、出力が `g + (1−g)·LPF` となり、位相と低域枝の残留で指令どおり下がらなかった。48 kHz・6 kHz で内部ゲインを −10 dB に固定しても実出力は約 −6 dB、amount 1 の実測は −4.7 dB だった。検出しきい値では埋まらないため、処理本体をハイシェルフへ変えた。

自動試験の合格は聴感の合格ではない。許諾済みの実音声（サ行・母音・息・歌・高域雑音）での聴感評価は未実施。下の合成信号は、その代わりに測れる範囲だけを広げた記録である。

## 処理

出力は 1 本の high-shelf。コーナーは 4500 Hz。`0.45 × Nyquist` 以上になるレートでは、その値の `(1 − 1e-6)` 倍へ下げる。16 kHz では約 3600 Hz 未満、48 kHz 以上では 4500 Hz のまま。S = 1 なので alpha は `sin(w0) / √2` で、ゲインに依存しない。`cos(w0)` と `sin(w0)` はレート決定時に一度だけ計算する。

減衰指令が 0 dB のとき、未正規化の b と a は一致する。正規化後の TDF-II は状態が 0 なら入力とビット単位で一致し、追加の遅延バッファは無い。これは IIR の群遅延が 0 という意味ではない。0 dB 以外の係数は、平滑化した減衰指令から 16 サンプルごとに作り直す。状態は TDF-II のまま差し替える。`pow` と平方根はこの更新でのみ使い、割当はしない。

検出は音量そのものではなく、高域エネルギーと声帯域エネルギーの比を使う。高域は約 4.5–10 kHz、声帯域は約 200 Hz–4 kHz の定ピークバンドパス。どちらも `0.45 * rate` 未満へ幾何平均の中心と帯域幅から Q を取り、Q は 0.3–4 に収める。左右は大きい側の二乗を包絡し、同じシェルフを両チャンネルへ使う。attack は約 1 ms、release は約 60 ms。包絡係数はレート決定時に `exp(-1 / (rate * 秒))` で作る。

amount を `a`（0〜1）とすると、

- 減衰の天井は `−12a` dB。amount 0 で 0 dB、amount 1 で −12 dB
- しきい値は `3.0 − 0.4a`。amount 0 で 3.0、amount 1 で 2.6
- 比がしきい値以下なら開き 0。しきい値の 1.35 倍で開き 1。それ以上は 1 で止める
- 減衰指令は `天井 × 開き`。0 dB から天井までの範囲に収める

しきい値と天井は約 15 ms、減衰指令は約 8 ms で平滑化する。平滑化後の指令は、絶対値が 1e-6 dB 未満なら 0 にする。0 付近の指数減衰が非正規化数のまま残らないようにするため。シェルフ係数はその指令から 16 サンプルごとに更新する。検出フィルタとシェルフの遅延は、絶対値の大きい方が 1e-20 未満なら両方とも 0 にする。片方だけ消すと、しきい値のすぐ上で二つの遅延が回り続ける。ON/OFF の混合は約 15 ms でランプする。OFF は混合が 0 になったあと検出とフィルタを消し、以降は入力をそのまま返す。`reset` は検出とフィルタを消し、ランプ位置は残す。非有限の入力は処理中に 0 へ置き換え、フィルタ出力が非有限ならそのフィルタだけを消す。無効で混合が 0 のときは状態を触らない。

## 位置

`Voice::process` の中で、通常の内蔵チェーンまたは歌向けチェーンの後に置く。残響は `Voice` の外なので、歯擦音抑制の次に残響へ入る。コンプで持ち上がった高域を、残響へ送る前に下げるため。ノイズ低減は `rt_voice` より前なので、歯擦音抑制はノイズ低減の後になる。`music_input` は従来どおり声と残響のブロックを通さない。

分離時も本人用モニターは同じ `Voice` を通る。適用される設定は、その `Voice` を作った `Config` である。非分離では配信用と本人用が同じ `Voice` なので、音づくり画面の設定が両方に効く。分離時の本人用は `monitor_singing` / `monitor_talk`、配信用は本体の内蔵設定を使う。音づくり画面は本体だけを編集する。

本人用の `Config` は `live_output::Config::same_route()` の比較に入る。音声が動いているあいだにこの比較が変わる保存は、エンジンが「音声を停止してから出力構成を変更してください」で拒否する。音づくり画面が歯擦音を本人用へ書かないのは、この更新経路が音声停止を要求するためである。DSP が本人用の `Voice` で動けないという意味ではない。画面では分離中だけ「配信側に適用。自分用の音は変わりません」と出す。

## 設定

`builtin::Config.deesser` は `Option<DeEsserParams>`。`None` が OFF。`amount` は有限かつ 0〜1。範囲外は拒否する。旧 JSON は `deny_unknown_fields` のまま読め、項目が無ければ `None`。

Undo/Redo は既存の builtin Controller に乗る。音づくり画面の ON/OFF と量は、プリセット量の旧 API ではなくこの適用経路を使う。旧 API（ホームのプリセットや量）は `replace_deesser` を立てないので、いまの歯擦音抑制を残す。プロファイルや bundle で内蔵 FX を明示適用するときは `None` を含めて置き換える。カテゴリ自体が無いプロファイルは、適用前の歯擦音抑制を戻す。

未適用の歌向け下書きがある状態で歯擦音を変えたときは、成功した `deesser` を下書きへも写す。明るさなどの未適用の歌向け値は残す。ホームの段は、声の `active` が OFF でも歯擦音があれば段全体を ON とし、声も残響も OFF のときは折り畳みを「歯擦音のみ」とする。`active` 自体の意味は変えない。

## 数値評価

debug の `cargo test --locked --lib deesser`（2026-11-08、ハイシェルフへ変更したあと）。刺激は合成信号で、6 kHz の狭い雑音を歯擦音の代わり、200 Hz 基音と倍音（最高 3200 Hz）を母音の代わり、振幅 0.02 の白色雑音を息、振幅 0.2 の白色雑音を高域を含む持続雑音とした。検出比・減衰指令・実出力は分けて記録する。実出力は窓内の全体 RMS である。48 kHz の窓は処理開始から 250 ms を除いた 400 ms。

固定 −12 dB のシェルフ単体（検出を通さない、48 kHz、コーナー 4500 Hz）は、200 Hz が −0.000 dB、6 kHz が −8.988 dB、8 kHz が −10.932 dB。0 dB では未正規化の b と a が一致し、状態 0 の処理は入力と一致する。

| 歯擦音の代わり | 0.5 | 4.773 | −6.000 dB | −4.586 dB | 0.128 |

OFF と amount 0 は 5 つのレートで入力と一致し、インパルスの最大も先頭サンプルにある。片側だけの歯擦音でも両側を鳴らしたときと実出力は −8.892 dB で一致し、0.2 倍したチャンネルの比のずれは 0.02 未満。OFF の区間で、出力差が同じ区間の入力差を超えた量の最大は 0.014。OFF→ON は 0.025。量 0.2 から 1.0 への差分の最大は 0.084（直前の定常 0.109）。定常中に係数を更新したサンプルの差分の最大は 0.091（それ以外 0.109）。母音の `reset` 境界は 0.044 で、直前の定常と同じ。`reset` 後の母音は、同じように `reset` した未使用の処理器と一致する。非有限入力の次の有限サンプルも有限。処理・更新・`reset` の割当と解放は 0。

`Voice` の後段でも、OFF のあいだは通常チェーンと一致する。amount 1 の歯擦音の代わりは、先頭 8000 サンプルを除いた残りで −8.328 dB。

レート別の歯擦音は、16 / 44.1 / 48 / 96 / 192 kHz のすべてで実出力と減衰指令が −8 dB 以下であることを合格条件にしている。上の表はその範囲に入っている。

6 kHz の正弦を 1 秒処理したあと無音にすると、2 秒後の減衰指令とシェルフへ渡した値のビットパターンは 0 である。さらに 4 秒後、フィルタ遅延・両包絡・検出比・指令は 0 で、シェルフ係数は 0 dB の恒等である。

歯擦音の立ち上がりと終了で、減衰指令が 6 dB 以上動く区間の隣接サンプル差は、同じ信号を 0 dB と −12 dB の固定シェルフで処理した差を超えていない（大きい方の 1.25 倍 + 0.02 未満）。amount の 0→1、1→0、10 ms ごとの連打も同じ比較である。指令が −12 dB 付近のときに `reset` して無音へ入ると、無音の出力は 0 で、再開は未使用の処理器と一致する。OFF にして無音でランプを終え、再び ON にした再開も、固定シェルフの隣接差を同じ幅では超えない。

## 合成での誤検出の余裕

実音声は使っていない。窓は上の 48 kHz と同じく、先頭 250 ms を除いた 400 ms。色付きの息は、振幅 0.02 の白色雑音と同じ RMS に揃えた。ピンクは Paul Kellet の近似、ブラウンは係数 0.997 の漏れ積分、高域を強めた息は 3 kHz の一次ハイパスを 0.85・原音を 0.15 で混ぜた広帯域である。狭い 6 kHz の歯擦音刺激とは別物である。高音の合成母音は基音 400 / 700 / 1000 Hz で、倍音を 8 kHz と `0.45 × レート` の低い方まで残し、振幅は次数の −0.3 乗に 5.5 kHz 付近の山（`1 + 2.5·exp(−((f−5500)/1800)^2)`）を掛け、ピークを 0.25 にした。

## CPU とメモリ

`DeEsser` は 184 バイト、`Coefficients` は 80 バイト。クロスフェード中は `Voice` が 2 つある。リングバッファは持たない。

debug で 48 kHz・1 秒（48,000 フレーム）の処理は 27,034 µs。ignored の計測を方式変更後に一度実行した結果で、通常のテスト実行には含めない。最適化していない計測であり、release の最悪時間や実機の負荷は未計測。

## 外部 VST との比較観点

スキャン、エディタ、プラグイン報告の遅延は増えない。周波数や listen のつまみは無く、量だけである。左右独立ではなく連動する。既定 OFF なので、既存のチェーンは項目を書かない限り変わらない。聴感を確認する前に、調整済みの外部ディエッサーの置き換えとは扱わない。

## 採否

既定 OFF で追加。実音声（許諾済みのサ行・母音・息・歌・高域雑音）の聴感評価は未実施で、Issue の完了条件のうちこの項目は未達。合成では、amount 1 の 6 kHz 刺激の実出力が −8.9 dB、従来母音が 0.0 dB、白色の息と広帯域とピンクとブラウンが 0.0 dB、高域を強めた息は −4.3 dB まで誤って下がった。音が良くなったとは扱わない。強すぎると子音がこもる、という画面上の注意は残す。

## 未確認

- 1 時間の欠損（A-3）
- 実歌声の保持（A-5）。合成母音の RMS 差 0 dB は歌声の合格ではない
