# 内蔵ディエッサー（#457）

外部 VST を入れずに、サ行の鋭さを抑える分割帯域の歯擦音抑制を追加する。既定は OFF。旧設定・旧プロファイル・旧 bundle に項目が無いときは OFF のまま読む。第三者の実装や係数表は参照していない。RBJ の2次フィルタと、ローパスを引いた相補の高域だけで組んでいる。

自動試験の合格は聴感の合格ではない。許諾済みの実音声（サ行・歌・息）での比較は未実施。

## 処理

入力 `x` を2次 Butterworth ローパス（Q = 1/√2）に通し、高域は `x - LPF(x)` とする。出力は `x + (g - 1) * high`。`g = 1` のときは乗算を行わず、出力は入力とビット単位で一致する。遅延バッファは置かない。追加のサンプル遅延 0 は、IIR の群遅延が 0 という意味ではない。

交差は 5500 Hz。レートに応じて `200 Hz` 以上、`0.45 * rate` 以下へ収める。16 kHz でも Nyquist を越えない。

検出は音量そのものではなく、高域エネルギーと声帯域エネルギーの比を使う。高域は約 4.5–10 kHz、声帯域は約 200 Hz–4 kHz の定ピークバンドパス。どちらも `0.45 * rate` 未満へ幾何平均の中心と帯域幅から Q を取り、Q は 0.3–4 に収める。左右は絶対値の大きい側の二乗を包絡し、同じ `g` を両チャンネルへ掛ける。attack は約 1 ms、release は約 60 ms。係数はレート決定時に `exp(-1 / (rate * 秒))` で作る。

比がしきい値を超えた分だけ減衰する。amount を `a`（0〜1）とすると、

- 下限ゲインは `a = 0` で 1、それ以外は `10^(-10a / 20)`。amount 1 の天井は高域ゲイン −10 dB
- しきい値は `3.0 - 1.4a`。amount 0 で 3.0、amount 1 で 1.6
- 比がしきい値以下なら開き 0。超えたときは `clamp(1 - しきい値 / 比, 0, 1)`
- `g = 1 + (下限ゲイン - 1) * 開き`

しきい値と下限ゲインは約 15 ms で平滑化する。ON/OFF と量の変更で、ウェット混合を約 15 ms でランプする。OFF は混合が 0 になったあと検出とフィルタを消し、以降は入力をそのまま返す。`reset` は検出とフィルタを消し、ランプ位置は残す。非有限の入力は処理中に 0 へ置き換え、フィルタ出力が非有限ならそのフィルタだけを消す。無効で混合が 0 のときは状態を触らない。

## 位置

`Voice::process` の中で、通常の内蔵チェーンまたは歌向けチェーンの後に置く。残響は `Voice` の外なので、歯擦音抑制の次に残響へ入る。コンプで持ち上がった高域を、残響へ送る前に下げるため。ノイズ低減は `rt_voice` より前なので、歯擦音抑制はノイズ低減の後になる。`music_input` は従来どおり声と残響のブロックを通さない。

分離時も本人用モニターは同じ `Voice` を通る。適用される設定は、その `Voice` を作った `Config` である。非分離では配信用と本人用が同じ `Voice` なので、音づくり画面の設定が両方に効く。分離時の本人用は `monitor_singing` / `monitor_talk` の設定を使い、配信用は本体の内蔵設定を使う。音づくり画面は本体だけを編集する。本体のスライダーをモニターへ重ねると経路の同一性判定が変わり、機器の再起動を招くため、モニター用の設定が無いときは OFF のままにする。DSP は同じで、スライダーの複製ではない。

## 設定

`builtin::Config.deesser` は `Option<DeEsserParams>`。`None` が OFF。`amount` は有限かつ 0〜1。範囲外は拒否する。旧 JSON は `deny_unknown_fields` のまま読め、項目が無ければ `None`。

Undo/Redo は既存の builtin Controller に乗る。音づくり画面の ON/OFF と量は、プリセット量の旧 API ではなくこの適用経路を使う。旧 API（ホームのプリセットや量）は `replace_deesser` を立てないので、いまの歯擦音抑制を残す。プロファイルや bundle で内蔵 FX を明示適用するときは `None` を含めて置き換える。カテゴリ自体が無いプロファイルは、適用前の歯擦音抑制を戻す。

## 数値評価

debug の `cargo test --locked --lib deesser`（2026-11-08）。刺激は合成信号で、6 kHz の狭い雑音を歯擦音の代わり、200 Hz 基音と倍音を母音の代わり、振幅 0.02 の白色雑音を息、振幅 0.2 の白色雑音を高域を含む持続雑音とした。窓は処理開始から 250 ms を除いた 400 ms。高域は交差と同じローパスの補信号。

| 信号（48 kHz） | amount 0.5 全体 | amount 0.5 高域 | amount 1 全体 | amount 1 高域 | amount 1 のピーク |
| --- | ---: | ---: | ---: | ---: | ---: |
| 母音 | 0.000 dB | 0.000 dB | 0.000 dB | 0.000 dB | 0.243 |
| 歯擦音の代わり | −2.281 dB | −2.287 dB | −4.669 dB | −4.695 dB | 0.126 |
| 息の代わり | 0.000 dB | 0.000 dB | −0.081 dB | −0.095 dB | 0.020 |
| 広帯域雑音 | 0.000 dB | 0.000 dB | −0.072 dB | −0.086 dB | 0.200 |

母音の変化は 0.5 dB 未満。歯擦音の代わりは量を上げると深くなり、息と広帯域より 1 dB 以上深く下がる。amount 1 の全体が −10 dB に届かないのは、天井が「開ききったときの高域ゲイン」だからである。この 6 kHz 刺激は声帯域側にも漏れ、開きが 1 にならない。16 kHz では検出帯域が Nyquist 側へ寄るため、同じ刺激の全体変化は −7.138 dB まで深くなる。

| レート | amount 1 の母音 | amount 1 の歯擦音の代わり |
| --- | ---: | ---: |
| 16 kHz | 0.000 dB | −7.138 dB |
| 44.1 kHz | 0.000 dB | −4.618 dB |
| 48 kHz | 0.000 dB | −4.652 dB |
| 96 kHz | 0.000 dB | −4.439 dB |
| 192 kHz | 0.000 dB | −4.422 dB |

OFF と amount 0 は 5 つのレートで入力と一致し、インパルスの最大も先頭サンプルにある。片側だけの歯擦音でも両側を鳴らしたときと減衰は −4.652 dB で一致し、0.2 倍したチャンネルの比のずれは 0.02 未満。OFF への差分の最大は 0.108（定常 0.079）、量 0.2 から 1.0 への差分の最大は 0.094（定常 0.122）。`reset` 後の母音は、未使用の処理器と一致する。非有限入力の次の有限サンプルも有限。処理・更新・`reset` の割当と解放は 0。

`Voice` の後段でも、OFF のあいだは通常チェーンと一致し、amount 1 の歯擦音の代わりは −4.653 dB。

## CPU とメモリ

`DeEsser` は 160 バイト、`Coefficients` は 88 バイト。クロスフェード中は `Voice` が 2 つある。リングバッファは持たない。

debug で 48 kHz・1 秒（48,000 フレーム）の処理は 21,309 µs。最適化していない計測であり、release の最悪時間や実機の負荷は未計測。通常のテスト実行には含めない。

## 外部 VST との比較観点

スキャン、エディタ、プラグイン報告の遅延は増えない。周波数や listen のつまみは無く、量だけである。左右独立ではなく連動する。既定 OFF なので、既存のチェーンは項目を書かない限り変わらない。聴感を確認する前に、調整済みの外部ディエッサーの置き換えとは扱わない。

## 採否

既定 OFF で追加する。合成信号の数値条件は上表のとおり満たした。実音声の聴感は未確認なので、音が良くなったとは扱わない。強すぎると子音がこもる、という画面上の注意は残す。

## 未確認

- 許諾済みのサ行・歌・息での聴感比較
- 実機の往復遅延（A-1）。先頭サンプルに応答があることは、端子間の遅延ではない
- 1 時間の欠損（A-3）
- 実歌声の保持（A-5）。合成母音の RMS 差 0 dB は歌声の合格ではない
- 分離出力の実機。本人用と配信用が別の `Config` を持つことはコード上の境界で、配線した二系統の到達は未確認
- release ビルドの CPU 最悪時間と、長時間運転
