# 比較切替の改善版で連続運転と異常時停止を確認した

2026-11-02、[比較切替の改善](COMPARISON_SWITCH_TRANSITION.md)を含む実Engineで、Chrome・VLC各65分と異常時の停止・再選択を確認した。
取得は継続したが、callback遅延と音声待機を記録している。段階1の受入全体や「音切れなし」の判定にはしない。
以前の[改善前の記録](PROCESS_LOOPBACK_ACCEPTANCE_2026-11-02.md)はそのまま保持する。

## 同じ改善版でChrome・VLCを各65分運転した

試聴環境と同じEngineを使用した。SHA-256は`cc761f106d12ee94255a725d497fd5dbb7b8ad0259b4b96273ecb79e5327dec5`。
原音用の別出力をミュートし、プロセス取得→製品SRC→TDR Nova→Voicemeeter Inputの経路で運転した。
返しはDSP後の全体ミュートとし、聴感は確認していない。VSTを通す処理は継続した。
ChromeとVLCは別のEngine・原音用出力で同時に運転し、同じPCで素材採取などの作業も行った。結果は単独・無負荷条件ではない。

| 項目 | Chrome | VLC |
| --- | --- | --- |
| 再生元 | 専用Chromeのaudio要素 | VLCのWAVリピート |
| 取得／出力レート | 48／48 kHz | 48／44.1 kHz |
| 定常運転 | 3,900秒 | 3,900秒 |
| 取得失敗／不連続／時刻エラー／非有限値 | すべて0 | すべて0 |
| callback遅延の検出数 | 574 | 575 |
| 最大callback遅延 | 16,045 µs | 22,087 µs |
| 音声待機に伴うreset | 2 | 255 |
| 待機時に破棄した取得フレーム | 280 | 28,277 |
| 観測したキューフレーム範囲 | 678〜2,127 | 0〜6,613 |
| 観測した速度補正範囲 | −654〜2,000 ppm | −2,000〜2,000 ppm |

callback遅延は呼出し間隔からの検出値で、耳に聞こえた音切れの件数ではない。
Chromeの待機resetは開始後約342秒・346秒に増えた。VLCのログには素材のリピート241回があるが、reset全件がリピート由来とは確定していない。
補正上限への到達も観測したため、長時間の音質・待機・キュー挙動の評価は残す。

定常運転に入る前に、ラック音量0.25／bypass時1.0を往復して確認し、64回連打後も最後の要求の0.25へ戻ることを両アプリで確認した。
65分間ずっと切替を連打した試験ではない。
各試験が管理する原音用出力と返し用出力は復元・保持した。全試験終了後も、開始前の全再生先のミュート・音量・既定ロールとの一致を確認した。

## 終了・再選択・経路変更は所有するChromeで試した

[異常時の実Engine試験](../scripts/verify_process_input_faults.py)は、通常のChromeと分けた小音量素材の再生だけを操作する。
原音用2機器をミュートし、返しもミュートした状態で、次を確認した。

| 操作 | 観測 |
| --- | --- |
| 選択したChromeを終了 | 約1.13秒で終了・取得失敗の通知 |
| Chromeを起動し直して古い対象で開始 | 古いPID・生成時刻の対象を拒否 |
| 新しい対象を明示選択して開始 | 非ゼロの取得へ復帰 |
| Chromeの出力をもう一つのミュート済み機器へ変更 | 約1.08秒で経路変更の停止通知 |
| 原音用出力のミュートを解除 | 約0.19秒で経路変更の停止通知 |

通知時間はこの1回の観測値で、最大応答時間の保証ではない。
終了後に試験用Chrome・Engineを回収し、全再生先の設定が一致することを確認した。
機器の物理切断・無効化、Windows既定出力への移動、Chromeの子プロセスだけの再生成はまだ試していない。

## 次は実素材の聴感と残る実機条件を確認する

利用者提供の配信から同一PCMを用意し、[現行NRの素材比較](NR_MATERIAL_EVALUATION_2026-11-02.md)へ進めた。
この比較はオフラインの候補生成であり、プロセス入力の声の用途でのNR切替やマイク学習結果の実機保護を代用しない。
Host画面を含む長時間運転、ASIOマイク、マイク権限拒否、DPI・読み上げ、別VST・各サイトも残る。

証拠はignoredの`test-results/process-input-followup-20261102/`に保存した。
`chrome-65m`と`vlc-65m`の`summary.json`・`samples.jsonl`、`faults/summary.json`、全体の`verification.json`を参照する。
再現用の連続試験は[既存runner](../scripts/verify_process_app_soak.py)へ`--comparison-switches --seconds 3900`を指定する。
通常の自動テストへ音声開始を追加していない。
