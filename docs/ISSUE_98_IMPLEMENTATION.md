# Issue #98: 戻せる操作の案内（部分対応）

## 対応範囲

「戻す・復旧する」の折り畳み内に、NR候補、内蔵候補、固定出力ゲイン、プロファイル、配信状態、モニター試験の6項目について、対象と戻る基準を日英で表示した。これは静的な操作案内であり、現在のUndo可否や履歴を取得・表示するものではない。既存の操作・保存・API、stream状態のunknown/running/stopped/failed判定は変更していない。

現行実装を照合し、共通の競合保護がすべての操作にあるという旧説明は削除した。

- NR候補: 録音チェックの適用直前のNR設定。tokenと条件により復元可否を判定する。
- 内蔵候補: 内蔵設定の適用前。revisionとtoken、反映状況などの条件がある。
- 固定ゲイン: 音量チェックの適用前の出力ゲイン。調整結果から復元する。
- プロファイル: 適用前に自動保存されたバックアップ。確認済み構成とは別で、復元結果を確認する。
- 配信状態: 操作結果に保持された、対象項目の適用前の状態。競合・部分失敗を表示する。
- モニター試験: 試験前に保存した入出力設定。通常の試験中と中断後の復旧は確認条件が異なる。

本Issue全体は部分対応。期限・件数・再起動後のUndo契約の統一、新たな障害分類、その他の受入条件、実機・外部受信先確認は今回未対応。
