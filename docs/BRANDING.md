# Auralyn - Brand Identity & Concepts

## 1. アプリケーション名の由来
**Auralyn (オーラリン)**

*   **Aura (オーラ)**:
    *   「まとう空気感」「存在感」「目に見えない力」「輝き」。
    *   配信者の「声」や「空間」が持つ独特の雰囲気を指します。
*   **-lyn (リン)**:
    *   美しさ、響きの良さ、愛らしさを表す接尾辞（人名などにも使われる）。
    *   「Aura」の持つ神秘的なイメージに、親しみやすさと洗練された響きを加えています。

**コンセプト**:
「声という実体のないもの（Aura）を、美しく整えて届ける（lyn）。」
配信者が自分の「オーラ（雰囲気）」を最大限に発揮できるような、透明感のあるサポート役を目指しています。

## 2. コアバリュー (Core Values)
*   **Invisible yet Powerful (目に見えないが、力強い)**:
    *   裏方として配信を支えるが、その効果は絶大であること。
*   **Ethereal Clarity (天上の透明感)**:
    *   ノイズのない、透き通った音質と、クリアな操作画面。
*   **Solid Foundation (揺るぎない基盤)**:
    *   美しいだけでなく、ツールとしての堅牢性（Stability）を兼ね備えていること。

## 3. ビジュアル・デザイン言語
### キーワード
*   **Ethereal (幻想的)**: オーロラ、光のカーテン、霞。
*   **Prism (プリズム)**: 音の屈折、変換、多彩な表情。
*   **Flow (流動性)**: 止まることのないリアルタイムな情報の流れ。

### 色の考え方: 静かな面、一か所の光
*   面（背景・カード・枠線・文字）は色を持たない静かな段階で作る。配信者が何時間も見る画面なので、面が色を主張しない。
*   色は意味のある場所に集める。メーターの色は状態を示し、オーロラは本番帯の奥にだけ灯る。
*   オーロラは実物に近い色にする。大半は緑から青緑で、上端にだけ淡い赤紫が差す。シアンと紫のグラデーションは使わない。
*   面への色相グラデーション、すりガラス、操作部品の発光は使わない。いずれもAI生成のUIによく見られる表現で、Auralyn らしさにつながらないため。

### カラーパレット（アプリ）
*   **Deep Abyss**: 背景。わずかに青みのある黒。彩度は10%前後までに抑え、面が色として見えないようにする。
*   **Aurora Green / Aurora Teal**: オーロラの主な光。本番帯の奥の光、メーターの正常域、スイッチの ON に使う。
*   **Aurora Rose**: オーロラ上端の淡い赤紫。光の中にだけ少量使い、操作部品には使わない。
*   **Mist**: 主ボタンに使う明るい無彩色。暗い文字を乗せる。

旧パレットの扱い:
*   **Aurora Cyan / Mystic Purple**: アプリの画面では使わない。メーターの緑と色相が近く取り違えやすいこと、紫寄りの面がAI生成のUIの定番に見えることが理由。
*   **Luminous Gold**: アプリでは注意色（`warning`）と紛れるため使わない。

### アイコンコンセプト: "The Ethereal A"
*   **モチーフ**: 「A」の文字を形成する光の帯（オーロラ）。
*   **デザイン**:
    *   **Glassmorphism (すりガラス)**: 奥行きと透明感を表現。
    *   **Dark Background**: 深い闇（静寂）の中から光（音）が浮かび上がる対比。
*   アプリアイコンと Web サイトは旧パレット（シアン・紫・金）のまま。アプリの配色に合わせた改訂は別途検討する。

改訂の経緯（2026-10-31）: 旧パレットでは、紫寄りの紺の地、シアンと紫、すりガラス、発光を画面全体に使っていた。これがAI生成のUIの定番に近く見えたため、現行と3案を比較モックで比べ、「静かな面、一か所の光」の案を採用した。

## 4. 採用されなかったが重要なキーワード (Sub-concepts)
*   **SoundPilot**: ユーザーを導く「ナビゲーター」としての側面。
*   **Ether**: 空間を満たす媒質。ネットワークとの親和性。
