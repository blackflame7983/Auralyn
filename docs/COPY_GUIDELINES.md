# Auralyn ユーザー向け文言ガイドライン

**目的**: UI・LP・ドキュメントの表現を実際の性能に合わせ、「期待外れ」による失望と低評価を防ぐ。
**対象**: 日本語のユーザー向けコピー（アプリ UI、ランディングページ仕様、ストア説明など）。

本ガイドラインは `docs/CODING_GUIDELINES.md` の日本語 UX 指針と、`docs/PROPOSALS_AI_NOISE_HOST.md` のノイズ機能注意文方針を統合・昇格したものです。

---

## 基本原則

| 原則 | NG 例 | OK 例 |
|------|-------|-------|
| 効果は対象を限定して書く | 「あらゆるノイズを除去」 | 「ファン・空調などの持続的なノイズを低減」 |
| 消えないものを明記する | （無記載） | 「周囲の会話や BGM は完全には消えません」 |
| 断定より体感確認へ誘導 | 「プロ品質の声に」 | 「ボイスチェックで効果を確認できます」 |
| 数値は実測根拠があるものだけ | 「ノイズ −40dB」（宣伝上の固定値） | ボイスチェック等でユーザー環境の実測値を表示 |
| トレードオフを隠さない | 「遅延ゼロ」 | 「約 XX ms の遅延（画面に実測表示）」 |
| 「AI」の濫用を避ける | 「AI が声を完璧に」 | 「機械学習ベースのノイズ低減（RNNoise 系）」 |
| セットアップの難易度を正直に | 「複雑な設定はお任せ」「誰でも簡単」 | 「仮想ケーブルが必要な場合があります。つまずいたら接続診断をご利用ください」 |
| 学習機能の意味を正確に | 「AI が環境を理解して全部消す」 | 「3秒間の定常ノイズをプロファイル化し、抑制量を調整」 |
| アドバイスは非断定で | 「必ず改善します」 | 「改善する可能性があります」「検討してください」 |

---

## ノイズ低減（RNNoise / nnnoiseless）の注意文（常設推奨）

設定画面など、ノイズ機能の近くに次の趣旨を置く:

- **効く対象**: ファン・空調・電源ハムなどの**持続的なノイズ**
- **効きにくい対象**: 周囲の会話・BGM・突発音（**完全には消えません**）
- Krisp や NVIDIA Broadcast と同等の分離性能ではないことを暗に示す（誇張しない）

`PROPOSALS_AI_NOISE_HOST.md` より:

> BGM や周囲会話を完全に消すものではない

---

## 遅延の書き方

- 画面に**実測・推定レイテンシ（ms）**を表示する（DeviceStatus、MasterBar、設定モーダル）。
- 「低遅延」「ASIO 対応」は事実として書いてよいが、「遅延ゼロ」「ラグなし」は禁止。
- バッファサイズとトレードオフ（安定性 vs 遅延）を必要に応じて併記する。

---

## ボイスチェック・品質指標との連携

- 音質・ノイズ抑制の訴求では、静的な誇張より **「聴いて確認」** を優先する。
- 品質チェックのアドバイスは「可能性」「おすすめ」「検討」など非断定表現にする。
- 数値（SNR 改善量など）は参考情報であり、最終判断は試聴である旨を添える。

---

## 接続診断（トラブルシュート）

- 「原因を特定します」→ 実測ベースの「確認します」に寄せる。
- 「すべて正常」→ 「確認できた項目に問題はありませんでした」など、診断範囲を限定する。
- セットアップが難しい場合の**逃げ道**として診断への導線を張る。

---

## トーン・文体

- アプリ UI は既存に合わせ **です・ます調**。
- 技術用語の直訳を避け、ユーザーが取るべき行動が分かる日本語にする（`CODING_GUIDELINES.md` 参照）。
- 主観的な煽り（「プロ級」「美声」「作品レベル」）より、**何が起きるか**を効果ベースで書く。

---

## PR レビュー用チェックリスト

新規・変更のユーザー向け日本語文言をレビューする際、以下を確認する:

- [ ] ノイズ抑制の効果範囲（効く／効きにくい）が必要箇所で明記されているか
- [ ] 「完全に消す」「あらゆる」「プロ品質」「遅延ゼロ」などの NG 表現がないか
- [ ] 数値を宣伝に使う場合、ユーザー環境の実測表示と矛盾しないか
- [ ] Smart Learn / 会場モードが「定常ノイズのプロファイリング」等、正確に説明されているか
- [ ] OBS / Discord 向けに仮想ケーブル必要性が早い段階で触れられているか
- [ ] 音質に触れる箇所にボイスチェック（試聴）への導線があるか
- [ ] 接続診断が「簡単セットアップ」の代替導線として言及されているか（該当画面）
- [ ] 品質アドバイス・診断結果が断定しすぎていないか
- [ ] 「AI」表記が過剰でないか（機能名・説明が実態と一致しているか）
