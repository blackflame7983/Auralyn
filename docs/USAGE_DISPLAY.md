# 用途に合わせた表示（Issue #4）

配信をはじめる人は接続設定から音づくり・試聴とOBSの設定確認へ進み、VSTを使う人はエフェクト一覧から音を調整する。画面を分けるために別の音声設定やエフェクトチェーンは作らない。

既存の「かんたん表示」をそのまま使い、次の二つを同じ設定として扱う。

| 表示               | 主な操作                                                         |
| ------------------ | ---------------------------------------------------------------- |
| 配信向け・かんたん | 声を整える、録音して聴く、OBSを整える。音量チェックは必要時に表示し、VST操作は詳細を展開して利用する |
| VST・詳細          | 必要時に表示する音量チェックと従来のVST一覧。既存の詳細調整項目を利用する  |

かんたん表示でVST一覧を閉じても、適用中のエフェクト処理は続く。表示の切替ではデバイス・ゲイン・ミュート・VSTの適用状態を変更しない。音量測定は従来どおり明示的に開始するまで動かない。

## 初回セットアップと再訪

最初の画面は「用途を選んで設定する」を主操作、「OBS向けに設定する」を近道として示す。「設定後の表示」で「配信をはじめたい／VSTで音を調整したい」を選べる。受け側アプリの選択（OBS、ボイスチャット、音楽鑑賞など）とは分ける。OBSへ送るVST利用者も詳細表示を選べる。
選択は音声設定の適用成功後、または明示的な「スキップ（手動設定）」で確定する。中断・適用失敗・オーディオ設定へ移動するだけでは確定しない。

既存の `vst_host_beginner_mode` を正本として使い、新しい設定キーへの移行や既存ユーザーへの強制再選択は行わない。未設定時のかんたん表示、既存の詳細表示を維持する。ヘッダーの従来の表示切替と通常画面の切替ボタン、セットアップの確定が同じ保存値・イベントを通じて同期する。
VSTのチュートリアルは詳細表示で利用し、かんたん表示の閉じた一覧へ誘導しない。

「OBSを整える」は既存の設定画面のOBS連携タブを直接開く。接続・変更の適用は別の明示操作であり、入口を押しただけでOBSに接続したり設定を書き換えたりしない。通常の設定入口はオーディオタブを開く。「声を整える」はノイズ低減・内蔵ボイスチェーンをまとめた音づくりタブを直接開く。これらの変更は即時反映し、入出力の「保存して開始」と分ける。

## 検証

- 初回選択の両方を適用成功・中断・失敗・明示スキップで確認する。
- 既存表示の保持、複数の切替箇所と別ウィンドウからの保存値変更の同期を確認する。
- OBSへの直接導線と通常の設定入口の戻り先を確認する。
- 900×600で切替・VST詳細の展開・OBS設定・初回選択を操作し、音声と保存設定を試験後に戻す。

未使用時の測定停止とOBS接続・履歴の扱いは [BROADCAST_LIFECYCLE.md](BROADCAST_LIFECYCLE.md) を参照する。
固定ゲインの提案と聞き比べは [AUTO_GAIN.md](AUTO_GAIN.md) を参照する。配信用部品の総合的なCPU・メモリ比較は別途検証する。
