# 用途に合わせた表示（Issue #4）

配信をはじめる人は接続設定から音づくり・試聴とOBSの設定確認へ進み、VSTを使う人は右パネルの VST 構成から音を調整する。画面を分けるために別の音声設定やエフェクトチェーンは作らない。

以前の表示モード（「配信向け・かんたん」「VST・詳細」）は廃止し、ホームを1種類にした。外部 VST を使わない人（ゲームセンター配信などでノイズ低減だけを使う人）でも、同じホームで迷わず使えるようにするため。役割は次の3つに分けた。

| 入口 | 内容 |
| ---- | ---- |
| ホーム | 本番帯（声のレベル・入力機器・送り先・歌／雑談）、声の処理（ノイズ低減・内蔵ボイスチェーン・VST の1行）、準備状況 |
| 右パネル「VST 構成」 | 声の処理の「VST を編集」（外部 VST がないときは「追加」）から開く。並べ替え・ゲイン・削除・表示形式・プロファイル管理・テンプレート |
| 外観「数値の詳細を表示」 | ヘッダーの遅延、設定の推定遅延・ノイズ低減の強さ（%）、ピーク保護を開いた状態 |

右パネルを閉じても、適用中のエフェクト処理は続く。パネルの開閉や数値の詳細の切替ではデバイス・ゲイン・ミュート・VSTの適用状態を変更しない。音量測定は従来どおり明示的に開始するまで動かない。

## 初回セットアップと再訪

最初の画面は「用途を選んで設定する」を主操作、「OBS向けに設定する」を近道として示す。「設定後の表示」で「配信をはじめたい／VSTで音を調整したい」を選べる。受け側アプリの選択（OBS、ボイスチャット、音楽鑑賞など）とは分ける。「VSTで音を調整したい」を選ぶと、右パネルを開き、数値の詳細も出す。もう一方を選ぶとパネルを閉じ、数値の詳細は変更しない。初期選択は現在のパネルの開閉に合わせるため、そのまま保存しても開閉は変わらない。
選択は音声設定の適用成功後に確定する。音楽鑑賞では保存値の読み戻し確認にも成功してからパネルを開閉する。中断・スキップ・適用失敗・オーディオ設定へ移動するだけでは確定しない。

数値の詳細は既存の `vst_host_beginner_mode` を正本として使い、新しい設定キーへの移行や既存ユーザーへの強制再選択は行わない。右パネルの開閉は `auralyn_vst_panel_open` に保存し、未保存の間は `vst_host_beginner_mode` が `false`（以前の「VST・詳細」）か、表示用途が音楽鑑賞（音を VST 構成で整える）なら開いた状態から始める。セットアップで VST を選んだときは、外観のスイッチと同じ保存値・イベントで数値の詳細を ON にする。
VSTのチュートリアルは右パネルを開いている間だけ進め、閉じたパネルへ誘導しない。

「OBSを整える」は既存の設定画面のOBS連携タブを直接開く。接続・変更の適用は別の明示操作であり、入口を押しただけでOBSに接続したり設定を書き換えたりしない。通常の設定入口はオーディオタブを開く。「詳しく調整」はノイズ低減・内蔵ボイスチェーンをまとめた音づくりタブを直接開く。これらの変更は即時反映し、入出力の「保存して開始」と分ける。

## 検証

- 初回選択の両方を適用成功・中断・失敗・明示スキップで確認する。
- 以前の表示の保持（VST・詳細だった人は右パネルと数値の詳細が出る）と、別ウィンドウからの保存値変更の同期を確認する。
- 右パネルが 1100px 以上でホームの横に並び、それより狭いとホームに重なること、どちらでも本番帯を操作できることを確認する。
- OBSへの直接導線と通常の設定入口の戻り先を確認する。
- 900×600で右パネル・OBS設定・初回選択を操作し、音声と保存設定を試験後に戻す。

未使用時の測定停止とOBS接続・履歴の扱いは [BROADCAST_LIFECYCLE.md](BROADCAST_LIFECYCLE.md) を参照する。
固定ゲインの提案と聞き比べは [AUTO_GAIN.md](AUTO_GAIN.md) を参照する。配信用部品の総合的なCPU・メモリ比較は別途検証する。
