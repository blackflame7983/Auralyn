# 設定項目の棚卸しと、G2 での置き場所（2026-11-12）

現行の設定モーダル（6区分）の項目を、G2 のどこに置くかを対応づけた表です。
実装の前に「置き場所のない項目がない」ことを確かめるために作りました。

## 調べ方と範囲

- 開発プレビュー（`?mock=live-home&screen=settings-<区分>`、Chromium）で各区分を開き、画面の文字と操作部品を読み出しました。
- 模擬応答で表示される状態だけを見ています。ASIO を選んだとき、OBS に接続したとき、VST を読み込んだときにだけ出る項目は、読めていません。
- コードには入力・出力のチャンネルを選ぶ部品（`InputChannelSelector.tsx`、`OutputChannelSelector.tsx`）がありますが、模擬応答の画面には出ませんでした。置き場所は「接続」の入力・出力の中と仮に決めています。
- 実機（Tauri）では確認していません。

## 行き先の分け方

| 行き先 | 入れるもの | 分ける理由 |
| :--- | :--- | :--- |
| ホーム | 毎回触る音調整（ON/OFF・強さ・整え具合・VST の ON/OFF） | すぐ反映するものだけ |
| 音づくり（レール） | 現行「音づくり」の全部 | 音を変える操作を1か所に集める |
| VST（レール） | VST の並び・追加・プリセット | 現行は別パネル。作り込む人の主な作業場 |
| 接続（レール） | 現行「オーディオ」の全部 | 音が通る道。保存して再起動が要る |
| 設定 | 外観・ホットキー・OBS連携・システム | アプリの動作。音の通り道は変えない |

【根拠のある判断】現行の「音づくり」は、すぐ反映する項目（ノイズ低減、声の基本）と、適用するまで反映しない項目（歌向け、ピーク保護）が同じ区分に並んでいます。G2 では小区分で分け、見出しの下の一文で反映のしかたを示します。

【好みによる判断】OBS連携を「接続」ではなく「設定」に置きました。OBS連携は OBS を操作するための連携で、音の通り道ではないためです。「接続」に入れる案もあり得ます。

## 置き場所が決まっていないもの

読み出した範囲では、ありません。

段階 D で、模擬応答では出ていなかった項目の置き場所を次のとおりにした。

- ASIO を選んだときだけ出る項目（入力・出力のチャンネル選択など）は、接続のページの入力・出力の中に置く。区分は移さない。
- OBS に接続したときだけ出る項目は、設定のページの OBS連携の中に置く。
- 診断情報の表は、システムの本文には開かず、「診断情報を開く」からダイアログで開く。表の中身は変えない。
- VST を読み込んだときだけ出る項目は、右パネルのまま（段階 F）。

実機の ASIO 選択時・OBS 接続時の画面は、未確認のままです。
