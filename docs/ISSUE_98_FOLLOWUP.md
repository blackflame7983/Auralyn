# Issue #98 後続のローカル実装（2026-10-28）

## 対応範囲

- NR候補・内蔵処理・固定ゲインそれぞれの最新1操作に、変更前／実際の変更後を往復するUndo/Redoを追加した。多段・全設定横断の履歴ではない。
- 時間だけの失効を取り除き、対象の編集・入力／学習／音声条件・エンジン世代等で検証する。固定ゲインの設定履歴は録音・試聴セッションから分離し、画面終了時のCancelでは消さない。
- 反映ACKを待ち、反対側の操作を有効化する。NRにも音声スレッドの適用revision応答を追加した。旧世代の固定ゲイン要求はepoch照合で拒否する。
- 復旧一覧に、明示取得による現在のUndo/Redo方向・未確認・反映待ち・本番保護と、操作対象を表示する。NRの履歴取得は録音画面の所有権を奪わない読み取り専用操作とする。
- 未設定・停止・stream失敗、機器を一意に識別できない状態、VST復元の保護、OBS未接続、取得失敗を観測できる範囲で案内する。内部の復旧と受け側で聞こえた確認を分ける。
- 配信状態の未解決原本を永続receiptとして保持し、新規適用による上書きを防ぐ。再起動後は差分を確認した明示復元または現在状態の採用とする。OBSのミュート解除を伴う復元は拒否する。
- モニター試験の未完了原本を通常／一時利用ごとに永続保存する。旧sessionStorageは保存成功後に移行する。破損・機器不明・未完了の原本は黙って捨てず、明示的な解決まで次の試験を止める。
- 復旧では元の機器IDを保持・照合し、実際に開くCPAL機器もIDで拘束する。ID不明の古い原本は自動代替しない。明示StopやA→B→Aの間接変更は条件revision／epochによって開始直前にも検証する。
- プロファイルの既存1世代バックアップは維持する。プロファイル・配信状態・モニター試験に汎用Redoは追加しない。
