# Issue #111 後続のローカル実装（2026-10-28）

## 対応範囲

- 表示用途と音声設定の適用は分離する。表示・ウィンドウ・ラックの共通変更は [ISSUE_109_FOLLOWUP.md](ISSUE_109_FOLLOWUP.md) を参照。
- 音楽セットアップの明示的な保存・開始では、NR・声の処理・内蔵残響をOFFにする。プリセット・強度・残響パラメーター・VST・ゲインは保持する。設定の読み戻しと失敗時の条件付き復元を維持する。
- 「再生音を聴いて確認」は手順・選択中の入出力・メーターの確認欄を開く。再生・録音・Windows出力変更を自動実行しない。開くと見出しへフォーカスし、閉じると入口へ戻す。
- 音楽の音量チェックは明示的な1操作開始を利用し、再生アプリからの入力を案内する。LUFS・True Peak・クリップ警告を表示し、声向けの良否判定・目標選択・自動音量合わせを標準表示に出さない。
- 設定移行の用途検証に `music` を追加した。表示復元だけで音声設定を再適用しない。

## 確認と残件

- セットアップ、音楽測定、確認欄、移行の自動テストを実施。統合候補の最終結果は [ISSUE_98_FOLLOWUP.md](ISSUE_98_FOLLOWUP.md) にまとめる。
- ブラウザモックで音楽確認欄へのフォーカス、閉じた後の入口への復帰、1操作での測定開始と音楽向け案内を確認した。モックの音声値・機器・準備状態は実音声の証拠ではない。
- 標準経路は仮想ケーブルを維持する。選択した再生エンドポイントのWASAPIループバックは、二重再生・自己循環を避けられる構成の限定実機検証が先となるため、直接取り込みエンジンは今回追加していない。採否・提供条件は `PLAYBACK_CAPTURE_RESEARCH.md` とIssue #111に従う。
