## 3. 変えないこと（F1b-0 でも今のまま）

- 状態の読み取り（`get_audio_state` など）が、先に受け付けた操作の完了を待つ境界（K2・K10、6.4）。待たない読み取りは F1b の `SnapshotCell`（D-8）。
- 旧の通知の名前・中身・数。reader が各行で直接出し、間引き・畳み・後送りはしない（PRE-F1b-12 (1)）。
- エラーの文言（新しく足す C2〜C5 の文言を除く）。
- 受け付けた順の記録（F1a-0）と、`engine_generation` の更新点。
- 配信セット・プロファイルの適用の途中の確認点（増やすのは F1b）。
