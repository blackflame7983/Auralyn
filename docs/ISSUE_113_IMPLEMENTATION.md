# 歌唱時の直接モニター案内（Issue #113）

## 変更内容と判断

- OBS ガイドの最初に、加工した声を Auralyn から聴く方法と、機器の直接モニターで加工前の声を聴き Auralyn を配信側に使う方法を追加した。既定は従来の加工後の声を聴く方法であり、選択自体は音声や機器の設定を変更しない。
- 直接モニターでは機器の対応を自動判定せず、機器の説明書と自分の耳で確認する。Auralyn の出力は仮想ケーブルなど OBS 向けとし、Auralyn・OBS のモニター音を直接音へ重ねないよう案内する。二重音などの症状に対する切り分けもこの経路に合わせた。
- 機器ループバックの選択を直接モニターの条件にしない。従来の加工後の声を聴く経路の機材分岐、設定変更、二系統出力・処理分離は維持する。
- 直接経路のチェックは、機器からの加工前の声、二重返しの不在、OBS 録画での声と伴奏のタイミングを手動確認する。音声・機器・OBS の到達や対応を自動保証しない。
- 手動確認の保存先は `auralyn_singing_route_direct` とし、従来の `auralyn_singing_route`（schema 1）を上書きしない。経路と接続の指紋を分け、構成変更・停止などの既存イベントでは画面上のチェックと確認済み表示を失効する。
- 明示的なボタンから既存の OBS 録画チェックと同期調整を開く。混合済みかどうかの既存確認、録画に基づく方向・差分の入力、プレビューと適用の明示操作を保つ。内部遅延を同期オフセットへ自動転記しない。
