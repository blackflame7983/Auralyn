# 表示と補足の整理（Issue #107）

## 変更内容と判断

- 内蔵ボイスチェーンの説明を、現行のローカット・コンプ・音色補正と ±0.98 の波形切り詰めに合わせた。音割れを完全には防げないことも示す。別の最終出力ピーク保護とは区別し、DSP は変更していない。
- VST のスキャン失敗、復元・操作の通知、保存済み構成の保護通知を分けた。保護中も一覧を表示し、追加分が自動保存されないことを案内する。復元や保存の条件は変更していない。
- 音量チェックの表示名を操作名とし、開始・停止の説明をアクセシブルな説明へ移した。
- 押して開く共通の情報ポップオーバーを追加し、ノイズ低減の範囲、声の保護、バッファ時間、高速設定の注意、入出力プリセット、ラックの折りたたみ、音量チェックの範囲を表示する。既存の Radix Popover を使い、日英それぞれ名前を付けた。
- 音声入力中の冗長な状態文字、VST の ON/OFF の言い換え、未設定メーカー名、テーマ保存の注記を整理した。ミュート表示とスイッチの状態は維持する。OBS のパスワード共有範囲は未接続時にも残す。
- ボイスチェックの試聴欄は録音前に折りたたむ。録音完了、再生・処理中、失敗、停止未確認、競合時は開き、停止と再試行に到達できる。手動で開いて先に試聴先を確認することもできる。
- ホットキーの詳細は情報ポップオーバーへ移し、操作条件を保持した。外観のシステム設定入口は、タブがまだ常設されていないため保持した（#110 の対象）。
