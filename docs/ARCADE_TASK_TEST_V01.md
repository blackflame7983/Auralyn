# ゲーセン配信の作業テスト（#72 V-01）

準備日: 2026-11-02。対象方針は [優先順位の見直し](STRATEGY_REVISION_2026-11.md)、評価方法は [評価軸](EVALUATION_CRITERIA.md)。本書は実施手順であり、被験者による結果はまだない。記録には [空のテンプレート](templates/arcade-task-test-v01.md) を使う。

## 目的と対象者

持ち込みPCで、起動 → 周囲測定 → 同じ録音でNR比較・採用 → OBSまたは通話の送り先確認 → 終了 → 自宅設定の確認を通す。最初に機器を接続する人と、前回と同じ条件で再訪する人を分ける。配信・VST・Auralynの経験を記録し、「初回」をアプリ初使用と現場初使用に分ける。同じ参加者の練習後の回を独立した初回の人数へ加えない。

利用者が参加者を募集し、録画・録音・観察記録の許諾を取る。実店舗では店の許可と周囲の人の扱いを確認する。準備段階は自宅の隔離環境で模擬できるが、模擬を実店舗の成功として集計しない。素材や個人名・送り先の識別情報はリポジトリ外へ置く。

## 実施前に固定する条件

- buildのcommit・未コミット差分、Host/sidecarのhash、Windows・機器・driver・rate/buffer/ch、画面寸法・DPI、OBS/通話アプリの版、受信側のNR/AGCを記録する。
- 通常利用の自宅設定を、利用者が明示保存した状態でバックアップする。音声選択ID/ch/gain、NR、内蔵処理、VST順序・state、出力経路・trim・歌/雑談・保護設定を記録する。未保存runtimeの完全復帰は未対応があるため、#221/#222の対象範囲と分ける。
- プロファイル管理の「一時利用」はアプリを再起動し、保存領域とWebViewを分離する既存機能である。未保存の現在音を丸ごと引き継ぐ機能ではない。通常側で保存する時間、一時利用へ入り直す時間も計測する。
- 配信・公開通話は開始せず、非公開のテスト録画または同意した受信者で行う。独立試聴先とOBSのデスクトップ音声・モニター・ループバックを点検し、試聴やテスト音の混入を防ぐ。緊急ミュートと停止を参加者へ示す。異常な大音量・意図しない送出があれば直ちに中止する。
- 比較する旧導線は固定旧buildと別設定で用意する。実施順を交互にし、練習効果・支援回数を記録する。旧buildがない場合は比較未実施とし、過去の所要時間を推定しない。

## 参加者に渡す課題

「このPCとマイクで、周りの音を抑えながら声を送り先へ届けてください。納得できる音を選び、短いテストで届いたことを確かめたら終了し、自宅で使う設定が残っていることを確かめてください。」

初回観察ではボタン名や正解の順序を教えない。操作を誘導した時点と内容を記録する。助言後の完了を無支援の成功へ含めない。断念・中断を認め、最大所要時間や助言条件は実施前に記録する。

## 観察者用の一本道

| 段階 | 参加者の作業と確認する結果 | 時刻・観察 |
| --- | --- | --- |
| 0 自宅の原本 | 保存済み自宅設定を記録し、一時利用を開始する。範囲外の未保存状態を了承できるか | 全体計測の開始。入口発見、説明の読み違い、再起動待ち |
| 1 起動・入力 | 持込PCの今回の機器を明示選択し音声を開始する。入力メーターで声が入る | 起動指示から入力成立。ID/chと表示、失敗と再試行 |
| 2 周囲測定 | 場所・用途・混合/別経路を選び、周囲の音を測る。声を出さない測定区間を分ける | 測定開始・終了、古い条件の再利用、取り直し |
| 3 比較・採用 | 固定した声/許諾素材を録音し、ボイスチェックのNR候補を同じ録音で比較して採用する。取消・戻す操作も記録 | 比較に使った時間、候補数、納得度、語尾/声の欠け、誤採用 |
| 4 送り先 | OBSの指定ソースと短い最終録画、またはOBS未起動の通話で相手の受信を確かめる | 到達までの手数と時刻、二重音/生音/試聴音混入、実録画と聴感 |
| 5 終了 | 音声・録音・試聴を止め、一時利用を終了する。必要な音作りだけ明示exportし、通常設定へ自動コピーしない | 終了/再起動、残存ファイルや削除失敗、再開の有無 |
| 6 自宅へ戻る | 通常設定を確認してから明示開始し、自宅機器・NR・FX・VST・経路が保存時と一致するか照合する | 原本比較と復帰完了時刻。受信側で再確認、差異は項目別に記録 |

操作位置と確認の意味は [準備導線](PREPARATION_FLOW.md) に従う。画面の確認マーク、メーター、キュー診断だけでは受信側の実音声を合格にしない。「原音比較」はVSTだけを外す既存操作であり、NR比較にはボイスチェックの専用候補比較を使う。一時利用の終了後も録音・適用・音声を自動再開させない。

## 初回・再訪・変化後を分ける

同一条件での再訪、別の入力機器、周囲騒音の変化は別試行にする。場所・入力・NRなどを変えた後に古い確認が失効するかを観察する。物理つまみやVST独自GUIの変更は自動検知保証外なので、参加者が再確認へ進めるかも記録する。

本番保護や分離モニターなどを使う参加者は別構成として記録する。未対応の保存・復帰を使う試行では、nativeが拒否することと利用者が理解できることを確認し、制限を外して通さない。

## 集計と次の判断

主要時間は「起動指示→受信側の声確認」と「終了指示→自宅設定照合完了」。一時利用へ入る準備時間、測定、比較、送り先の各時間も残す。初回/再訪/変化後、OBS/通話、無支援/支援後で分け、試行数・人数・成功/断念/中止/未確認を併記する。小人数の結果を一般化しない。

迷いは発生箇所・言葉・戻り操作・やり直し回数、誤送出は何がどこへ出たか・開始/停止時刻・対処を残す。誤送出の有無を確認できなかった回は「0回」としない。満足度だけで成功判定しない。

E-1（初回）、E-2（再訪）、E-3（NR調整）、E-4（流れ）、F-3（送り先）、C-5（原本保護）、C-6（誤送出）に対応する。#109の構成案の採用判断には実施結果を使う。手順とテンプレートの追加だけでは、これらの評価判定は変えない。
