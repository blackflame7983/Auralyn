## 環境を記録する

既存ユーザー用と初回用には、別のWindowsテストアカウントを使う。普段のAppDataやlocalStorageを削除して初回状態を作らない。
初回用アカウントでは音声設定やVST登録を引き継がず、既存用は必要なテスト設定を事前に用意する。
音声の送出・試聴の聴感は別の確認とし、この手順を始めるために音声を開始する必要はない。

倍率を変更したらAuralynを開き直し、OS設定の値と画面の状態を記録する。倍率と解像度は別々に記録する。
NarratorはWindowsの設定から有効にするか、`Ctrl + Windows + Enter`で起動する。

## キーボードと読み上げを確認する

マウスを使わず、`Tab`／`Shift + Tab`、矢印、`Enter`、`Space`、`Escape`で操作する。
各画面で、操作名・選択状態・無効状態・エラーが読み上げられ、フォーカスが見えることを確認する。
ダイアログを閉じたら開いた操作へ戻ること、背景へフォーカスが抜けないことも確認する。
