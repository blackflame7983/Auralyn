# 二入力と配信VSTの確認手順

専用の試聴用アプリで確認する。通常の設定とは別の保存領域を使い、最初は音声を停止した状態から設定する。
自動試験と未確認事項は[実装・確認記録](MIXING_STAGES_2_3_STATUS_2026-11-03.md)を参照する。

## 入力と出力を選ぶ

1. 試聴用アプリの`Start-Audition.cmd`を開く。
2. 音声設定で、主入力を声用途のマイク機器にする。本人用の出力は使っているヘッドホン経路を選ぶ。
3. 「歌・モニター」で本人用と配信用の処理を分け、配信用の出力を選ぶ。OBSにはこの出力に対応する仮想ケーブルの録音側などを指定する。
4. 「オケを追加して配信する」を開き、現在の設定を読み込む。

プロセス入力では、Chromeや音楽プレイヤーの原音を、本人用・配信用とは別の出力へ送る。
Windowsの音量ミキサーなどでその原音用出力をミュートしたうえで、アプリと原音用出力を明示選択する。
原音用と本人用を同じ出力にまとめる構成には対応していない。
別出力を用意できない場合は、オケを仮想ケーブルへ流し、その録音側をオケの機器入力として選ぶ。
主入力と同じ機器はオケに指定できない。

## 音量と時間差を確認する

声とオケの音量・ミュートを個別に変えて確認する。
本人が原音を直接聴く場合は、Auralynからのオケ返しを切り、二重に聴かないようにする。
配信用の時間差は、正の値でオケを追加で待たせ、負の値で声を追加で待たせる。
既知の声の処理待ちは別に扱うため、表示値をそのまま本人の耳までの総遅延とはみなさない。

OBSでは、Auralynからのミックスと同じマイク・オケ・デスクトップ音声を重複して取り込まない。
従来のOBS同期オフセットを記録し、Auralynで調整した相対時間差を重ねて設定しない。
映像との時間差は、最終録音を見て別に調整する。

## ミックス後のVSTを確認する

1. 音声を停止し、「ミックス後の配信 VST」で状態を読み込む。
2. 保存済みラックを明示的に復元する。初回は空のラックを準備する。
3. VST一覧から追加し、配信VSTを有効にする。音量、ミュート、順序、編集画面を確認して保存する。
4. 音声を開始し、配信枝の録音で効果を比較する。

ミックス後VSTは本人用の返しには掛からない。
Voice Checkは声の確認用として使い、オケと配信VSTを含む最終音はOBSなど配信枝の録音で確認する。
VSTの追加・削除・順序の変更は音声を停止して行う。
通常の音楽鑑賞は、従来のプロセス単独入力と単独ラックを使える。

## 保存・復帰と再起動

全体を保存する場合は、全カテゴリに加え、分離出力、本番モード、オケ・ミックス後VSTを含める。
復帰とUndoは全体ミュート中に行い、成功表示の後に入力元・音量・出力を確認してから解除する。
再起動後はオケの入力元を再選択し、保存したミックス後ラックも明示的に復元する。
保存されたアプリ名やPIDによる自動接続は行わない。

復帰が未完了の場合は送出を停止し、保管された原本を使って手動で復旧する。
壊れたオケ設定や配信VST設定は、それぞれの復旧操作で元の内容を保管して無効にできる。
復旧前の原本は、内容を確認できるまで残す。
