## 入力をつなぐ {#connect}

1. 仮想ケーブルを使う場合、Auralynの出力をCABLE Inputにします。
2. Discordの音声・ビデオの設定で入力をCABLE Outputにします。
3. マイクテストや入力メーターで確認し、声を聴きます。

機器のループバックを使う場合は、その機器の配信用入力を選びます。相手の声がループバックに混ざると、相手へ声が戻ることがあります。Discordの出力を別のヘッドホン端子へ出すか、機器の経路を調整してください。

## 処理の重なりを比べる {#processing}

1. Discord側のノイズ抑制をオンとオフで比べます。
2. 自動音量調整と入力感度も一つずつ比べます。
3. いつもの声が途切れず、背景音だけで反応しすぎない設定を選びます。
4. エコー除去を変える場合は、スピーカーの音をマイクが拾わないか確認します。

一律にすべてをオフにする必要はありません。ほかの通話アプリでも入力機器と処理の重なりを確認します。

## 届かないとき {#verify}

「音のトラブルを診断」で入力と出力を確認します。ガイドを閉じただけでは到達確認になりません。診断のテスト音は通話外で使ってください。
