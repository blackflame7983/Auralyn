## 接続方法を選ぶ {#connect}

仮想ケーブルを使う方法と、機器のPC戻りをループバックで渡す方法があります。後者は機器のドライバーとループバック対応が必要です。

1. 仮想ケーブルが未導入なら、既存のOBSガイドで案内されるVB-CABLEを準備します。導入後はPCの再起動が必要な場合があります。
2. Auralynの出力をCABLE Inputにします。
3. OBSで音声入力キャプチャのソースを追加し、機器にCABLE Outputを選びます。
4. OBS側のミュートを確認し、声を出してメーターを確認します。

ループバックを使う場合は、Auralynの出力を対応する機器へ戻し、OBSではその機器の配信用ストリームを選びます。具体的な名称は機器によって異なります。

## 自分で聴く {#monitor}

仮想ケーブルに出した音は、スピーカーから直接は聞こえません。OBS経由やWindowsのモニターには遅延が加わります。歌の返しとして使う前に聴いて確認します。同じ声を直接モニターとOBSの両方で聴いていないかも確認します。

## 最終録画を確かめる {#verify}

1. 配信・通話へテスト音が出ない状態にします。
2. デスクトップ音声や別のマイクで同じ音を重複取得していないか確認します。
3. 録画対象のトラックとミュートを確認します。
4. 短く録画し、声と伴奏のバランスを聴きます。

「ボイスチェック」は声単体の確認です。OBSの最終ミックスや録画トラックまでは確認しません。
