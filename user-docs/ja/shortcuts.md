## 使い方を開く {#help}

F1で「使い方」を開きます。入力欄にフォーカスがある場合も使えます。現在の割り当ては「キーボード操作」で確認できます。

## 操作一覧 {#actions}

登録できる操作は次のとおりです。すべての操作にキーが自動登録されるわけではありません。

- 「緊急ミュート（切替）」
- 「VSTを外して比較（切替）」
- 「歌モード」
- 「雑談モード」
- 「緊急ミュート（オン）」
- 「緊急ミュート（解除）」
- 「VSTを外して比較（開始）」
- 「VSTを外して比較（終了）」
- 「出力音量を1%上げる」
- 「出力音量を1%下げる」
- 「ノイズ低減を切り替える」

## キーを登録する {#assign}

1. 「設定」の「ホットキー」を開きます。
2. 操作ごとに修飾キーと通常キーの組み合わせを入力するか、一覧から選びます。
3. 「推奨のキーをまとめて入力」を使う場合も、入力された組み合わせを確認します。
4. 「キー設定を保存」を押して反映します。

登録は合計8件までです。歌・雑談の切替にはモードの事前登録が必要です。OSやほかのアプリと競合するキーを避けます。AltGrを使う配列では文字入力を妨げない組み合わせを選びます。

推奨キーの入力は未割り当てだけが対象です。既存の割り当てや重複、上限を超える登録は飛ばします。保存するまでは反映されません。

## Stream Deckで使う {#stream-deck}

1. Auralynでキーを保存します。
2. Stream DeckのSystem → Hotkeyに同じ組み合わせを設定します。

背面でも操作できます。Stream Deckの表示とミュート状態は同期しません。
