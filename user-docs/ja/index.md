## できること {#overview}

Auralynは、マイクの音にノイズ低減や声の調整、外部VSTの処理を加えるアプリです。配信・通話の前に、設定と試聴を済ませます。

## 用意するもの {#requirements}

WindowsのPC、マイク、音を聴く機器を用意します。OBSや通話アプリへ渡すには、仮想ケーブルが必要な場合があります。機器のループバックを使う場合は、その機器の対応と設定を確認します。

## はじめる順序 {#start}

1. [はじめの設定](./setup.md#purpose)で目的、マイク、出力を選びます。
2. [音を整える](./sound.md#noise-reduction)で少しずつ調整し、聴いて確認します。
3. [OBS](./obs.md#connect)や[通話](./discord.md#connect)の受け側で届くことを確認します。
4. 本番前に[ホーム](./home.md#stage)の状態を確認します。
