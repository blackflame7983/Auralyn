## Connect the input {#connect}

1. For a virtual cable, set Auralyn's output to CABLE Input.
2. In Discord Voice & Video settings, select CABLE Output as the input.
3. Use its microphone test or input meter, then listen.

For hardware loopback, select the device's streaming input. If loopback includes the other person's voice, it can send that voice back to them. Use a separate headphone output for Discord or adjust hardware routing.

## Compare overlapping processing {#processing}

1. Compare Discord noise suppression on and off.
2. Compare automatic gain and input sensitivity one at a time.
3. Keep your usual voice audible without excessive triggering from background sound alone.
4. If changing echo cancellation, check for speaker sound picked up by the microphone.

You do not need to turn everything off. Check input devices and overlapping processing in other calling apps too.

## If audio does not arrive {#verify}

Use “Diagnose audio problems” to check input and output. Closing a guide does not confirm reception. Run diagnostic test tones outside calls.
