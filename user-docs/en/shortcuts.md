## Open help {#help}

Press F1, or use “Help” at the bottom of the left rail, to open “How to use”, including when an input field has focus. View current assignments in “Keyboard shortcuts”.

## Actions {#actions}

These actions can be assigned. Keys are not automatically assigned to every action.

- “Emergency mute (toggle)”
- “Compare without VST (toggle)”
- “Switch to Sing mode”
- “Switch to Talk mode”
- “Emergency mute (on)”
- “Emergency mute (off)”
- “Compare without VST (start)”
- “Compare without VST (end)”
- “Increase output volume by 1%”
- “Decrease output volume by 1%”
- “Toggle noise reduction”

## Assign keys {#assign}

1. Open “Settings” → “Hotkeys”.
2. On each row, read the action and the current keys, then use “Enter keys”. An assigned key has a frame. “Not set” has no frame. “Choose from a list” and “Remove binding” sit at the end of the row or on the line below.
3. If using “Fill recommended keys”, review the filled combinations.
4. Select “Save key settings” to apply them.

There is a total limit of 8 bindings. Singing and talking switches require saved modes. Avoid keys reserved by the OS or used by other apps. On layouts with AltGr, choose combinations that do not block typing.

Recommended keys fill only unassigned actions. Existing assignments, duplicates and entries exceeding the limit are skipped. Changes take effect only after saving.

## Use Stream Deck {#stream-deck}

1. Save the keys in Auralyn.
2. Assign the same combinations in Stream Deck System → Hotkey.

These work while Auralyn is in the background. Stream Deck's display does not synchronize with mute state.
