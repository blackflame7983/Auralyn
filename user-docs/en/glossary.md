## Terms {#terms}

### Destination {#term-destination}

The purpose that uses your sound, such as streaming or calls.

It is separate from the output device and receiver confirmation.

### Virtual cable {#term-cable}

A virtual audio device that carries sound between apps.

Select paired devices for Auralyn output and receiving-app input.

### Noise reduction {#term-noise}

Processing that reduces steady noise such as fans and air conditioning.

It does not fully remove nearby speech or music. Listen for missing speech.

### Voice shaping {#term-voice}

Built-in processing that adjusts bass, volume differences and tone.

Compare before and after processing in Voice Check.

### VST {#term-vst}

An external plug-in that processes audio.

Manage the order in the VST area on Home and adjust values in each editor.

Search includes the two standard folders and any folders you add. Only VST3 plugins are supported.

### Current adjustments {#term-current}

The state when no saved singing or talking mode is in use.

Current changes are not necessarily saved.

### Singing and Talking modes {#term-modes}

Modes that switch saved voice adjustments.

Switching a linked VST setup can briefly interrupt sound.

### Singing mode {#term-singing}

A mode that uses adjustments saved for singing.

Save the adjustments before switching.

### Talking mode {#term-talking}

A mode that uses adjustments saved for talking.

Listen to the difference from singing before going live.

### Performance lock {#term-lock}

A feature that protects against accidental setting changes during a performance.

Stop and emergency mute remain available.

### Monitoring {#term-monitor}

Listening to your own voice through headphones or another device.

Hearing yourself does not confirm delivery to others.

### Clipping {#term-clip}

The state when sound reaches its level limit.

Lower input or output volume and check again.

### Buffer {#term-buffer}

Temporary storage for audio processing.

A larger buffer may reduce dropouts but increases latency.

### ASIO / WASAPI {#term-drivers}

Interfaces for connecting to audio devices.

Choose a method supported by your device in settings.

### ASIO {#term-asio}

An interface that uses a supported device's dedicated driver.

Check input and output channels for your device. It does not guarantee zero latency.

### WASAPI {#term-wasapi}

The standard Windows audio interface.

Check device and sample-rate settings when using it.

### dBFS {#term-dbfs}

A digital audio level unit with a ceiling of 0 dBFS.

Levels closer to zero are louder; reaching the ceiling can cause distortion.
